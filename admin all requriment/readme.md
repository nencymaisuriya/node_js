# 🛠️ My Admin Panel – All Requirements

A fully featured **Admin Dashboard** built using **Node.js**, **Express**, **MongoDB**, and **EJS**, with complete functionality including:

- Admin login/logout
- OTP-based password reset
- CRUD for Admins, Products, and Categories
- Multiple product image uploads
- Flash messages, cookie/session handling
- Responsive UI with Bootstrap

---

## 🚀 Tech Stack

| Layer       | Technologies                          |
|-------------|----------------------------------------|
| Backend     | Node.js, Express.js                   |
| Frontend    | EJS, HTML, CSS, Bootstrap             |
| Database    | MongoDB, Mongoose                     |
| Auth/Email  | Cookies, express-session, Nodemailer  |
| File Upload | Multer                                |

---

## 📁 Features

### 👤 Admin System
- Login with session cookies
- Logout
- Forgot password with email OTP
- Update password securely
- Create/Edit/Delete Admins

### 🛒 Product Management
- Add/Edit/Delete/View products
- Upload multiple images using Multer
- Support for categories, subcategories, and extra categories

### 🗂️ Category Management
- Add/Edit/Delete main categories
- Subcategories and extra categories support

### 🛡️ Security
- OTP stored in cookies
- Session secret for secure access
- Input validation and error handling
